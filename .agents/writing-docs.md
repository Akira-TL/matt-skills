# Matt Skill 文档规则

稳定 Skill 的人类说明位于 `docs/<bucket>/<skill-name>.md`，与 `skills/<bucket>/<skill-name>/SKILL.md` 一一对应。文档属于本仓，不再假设发布到外部网站，也不绑定特定执行器、plugin 或 marketplace。

## 什么时候同步

当稳定 Skill 新增、重命名、移动目录或发生实质行为变化时，同步对应文档。`in-progress`、`misc`、`deprecated` 默认不要求人类文档，除非该能力本身确有独立说明需求。

## 内容边界

文档解释：

- 这个 Skill 做什么；
- 什么时候应该使用；
- 关键前置条件与边界；
- 它在 Matt 工程流中的位置；
- 用户如何判断它是否发挥了作用。

文档不复制 `SKILL.md` 的完整执行步骤，不维护第二份安装说明，不为外部网站写专用链接结构。安装统一由 `akira` Router 管理。

## 链接

仓库内 Skill、文档与参考优先使用相对链接。确需引用外部资料时，链接应指向真实权威来源；历史上游网站链接不是本仓默认文档导航。

## 完成标准

- 稳定 Skill 与对应文档名称一致；
- 行为变化已反映到文档；
- 文档没有复制安装命令或外部分发机制；
- 文档中的流程关系与 `ask-matt` 当前路由一致；
- 仓库内链接可解析。
